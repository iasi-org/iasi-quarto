3  Instalación

3.1 Requisitos

Para utilizar iasi.quarto necesita:

  • R;
  • Quarto;
  • acceso a los formatos adicionales que quiera generar, por ejemplo una instalación TeX para PDF;
  • Git si va a instalar el paquete directamente desde GitHub.

Puede comprobar R y Quarto desde una terminal:

R --version
quarto --version

3.2 Instalar iasi.quarto

Una forma sencilla de instalar la versión disponible en GitHub es utilizar remotes:

install.packages("remotes")
remotes::install_github("iasi-org/iasi-quarto")

Después puede cargar el paquete:

library(iasi.quarto)

3.3 Comprobar la instalación

Compruebe la versión instalada:

packageVersion("iasi.quarto")

Y, desde una publicación IASI Quarto, ejecute:

validate()

Si el proyecto es válido, IASI Quarto lo reconocerá sin construir todavía ningún formato.
