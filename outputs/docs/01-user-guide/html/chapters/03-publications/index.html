4  Tipos de publicación

4.1 Estrategias soportadas

IASI Quarto soporta tres estrategias de publicación. La estrategia define cómo se interpreta la organización de los documentos fuente.

Estrategia Disponible para Organización editorial Cuándo utilizarla
regular Website y Book En un Book, cada carpeta de contenido forma una unidad y sus archivos .qmd se combinan. Cuando varios documentos fuente forman una única unidad editorial. Es la estrategia predeterminada.
structured Book Cada carpeta representa una Parte; su index.qmd presenta la Parte y los demás archivos .qmd son Capítulos. Cuando la estructura Parte → Capítulo debe estar representada explícitamente.
direct Book Cada archivo .qmd se publica directamente como Capítulo; las carpetas solo organizan los fuentes. Cuando cada documento ya es una unidad editorial completa.

Para un Website, la estrategia soportada es regular. Las estrategias structured y direct son propias de publicaciones de tipo Book.

4.2 Configuración de una publicación

Una publicación IASI Quarto combina la configuración de Quarto con _iasi.yml.

_quarto.yml continúa describiendo el proyecto Quarto. _iasi.yml indica cómo debe interpretar IASI Quarto su organización.

Una configuración mínima de libro puede ser:

publication:
  strategy: regular
  content-dir: chapters
  numbered: true

Los valores predeterminados para un libro son:

strategy    = regular
content-dir = chapters
numbered    = true

content-dir indica dónde se encuentra el contenido organizado de la publicación.

Cuando numbered: true, los documentos y carpetas de contenido que participan en el orden editorial utilizan prefijos numéricos, por ejemplo:

chapters/
├── 01-intro/
├── 02-installation/
└── 03-usage/

4.3 Crear un Website

Un Website utiliza el tipo de proyecto website de Quarto y la estrategia regular de IASI Quarto.

En _quarto.yml:

project:
  type: website

En _iasi.yml puede utilizar:

publication:
  strategy: regular

Para un Website, IASI Quarto no introduce las estrategias editoriales propias de los libros. La estructura y navegación continúan siendo las del proyecto Website de Quarto.

Para construirlo:

build(format = "html")

4.4 Crear un Book Regular

regular es la estrategia predeterminada para libros.

La idea es:

carpeta de contenido
    → capítulo o unidad de publicación

documentos .qmd dentro de la carpeta
    → contenido combinado de esa unidad

Ejemplo:

chapters/
└── 01-intro/
    ├── front-matter.quarto
    ├── 01-purpose.qmd
    └── 02-scope.qmd

IASI Quarto genera el index.qmd de la carpeta combinando los documentos fuente.

front-matter.quarto puede proporcionar el front matter del index.qmd generado:

---
title: "Introducción"
title-block-style: none
---

Por tanto, no edite el index.qmd generado. Edite los documentos fuente y, cuando corresponda, front-matter.quarto.

Use regular cuando una carpeta represente una unidad editorial formada por varios fragmentos o documentos fuente.

4.5 Crear un Book Structured

structured representa explícitamente Partes y Capítulos.

La regla es:

carpeta de contenido
    → Parte

index.qmd de la carpeta
    → presentación de la Parte

demás .qmd de la carpeta
    → Capítulos

Ejemplo:

chapters/
└── 20-methodologies/
    ├── index.qmd
    ├── 01-history.qmd
    └── 02-current.qmd

En _iasi.yml:

publication:
  strategy: structured
  content-dir: chapters
  numbered: true

A diferencia de regular, el index.qmd de cada carpeta es fuente y debe existir. IASI Quarto no lo genera a partir de otros documentos.

front-matter.quarto no participa en la estrategia structured.

Use structured cuando quiera que la jerarquía editorial Parte → Capítulo esté representada directamente por la estructura del proyecto.

4.6 Crear un Book Direct

direct publica cada documento .qmd como capítulo.

Las carpetas sirven para ordenar físicamente los fuentes, pero no crean Partes ni capítulos contenedores.

Ejemplo:

chapters/
├── 01-concepts/
│   ├── 01-model.qmd
│   └── 02-context.qmd
└── 02-usage/
    ├── 01-build.qmd
    └── 02-publish.qmd

La publicación resultante contiene los cuatro documentos como capítulos consecutivos.

En _iasi.yml:

publication:
  strategy: direct
  content-dir: chapters
  numbered: true

Use direct cuando cada .qmd ya sea una unidad editorial completa y las carpetas solo deban ayudar a mantener organizado el repositorio.

4.7 Elegir una estrategia

Si necesita… Estrategia
Un Website Quarto regular
Combinar varios archivos .qmd de una carpeta en una única unidad regular
Representar Partes que contienen Capítulos structured
Publicar cada archivo .qmd directamente como Capítulo direct

La elección es editorial. No depende del formato final: un mismo libro puede utilizar la misma estrategia para HTML, PDF, EPUB y otros formatos.
